# Calendario de Entregas — Biblioteca de Citas

> **108 entradas · 22 semanas · ~5 meses de contenido sin repetir.**
> Una entrada por día, lunes a viernes.

---

## Cómo usar este archivo

1. Abre el archivo al inicio de cada semana. Lee el tema y el hilo conductor.
2. Cada día: busca el número en [biblioteca-citas.md](biblioteca-citas.md) → copia el texto completo → publica.
3. Marca `[x]` una vez publicado.
4. Si saltas un día, continúa desde donde quedaste — el orden construye el hilo.
